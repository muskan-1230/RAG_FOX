# RAG_FOX

A Retrieval-Augmented Generation (RAG) system built from scratch in Python without LangChain.

## Features

- PDF Processing
- Text Chunking
- Embedding Generation
- FAISS Vector Search
- Gemini Integration
- Metadata Storage

## Project Structure

- ingest.py -> Creates embeddings and FAISS index
- rag_chat.py -> Retrieves chunks and generates answers

## Technologies

- Python
- FAISS
- Sentence Transformers
- Gemini
- PyPDF
